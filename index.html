Pulse App

Description

Pulse is a friends-only chat app where every message is analyzed for mood and rendered as a color-coded bubble, giving conversations an emotional layer without extra effort from the user. Built as a 10-phase flagship project to prove production Flutter fluency.

Key Features

  • Auto mood-detection on every message, shown as color-coded bubbles.
  • Friends-only social graph with real-time messaging.
  • Offline-first local cache with Hive, synced against Firebase.
  • Fully modular, feature-first Clean Architecture across all 10 phases.

Technical Stack

Dart BLoC / Cubit get_it / injectable go_router Firebase Hive ML Kit
